## 开发规范

### 代码风格
- 使用 ES5 语法（无 ES6+ 特性）
- 命名规范：变量用 camelCase，常量用 UPPER_CASE
- 函数命名：动词开头，如 `initSnake()`, `moveSnake()`

### 注释规范
- 所有函数必须有注释说明
- 关键逻辑必须有注释
- 使用中文注释

### Git 提交规范
```
类型: 简短描述

详细说明：
- 问题描述
- 原因分析
- 解决方案
- 测试结果

Commit: <commit-hash>
```

### 文件命名规范
- HTML 文件：`snake-game.html`
- Markdown 文件：小写 + 连字符，如 `snake-game-test-report.md`
- 配置文件：小写 + 连字符，如 `docker-compose.yml`

## 关键算法

### 蛇的初始化算法
```javascript
// 必须向初始方向相反的方向延伸
for (var i = 0; i < 5; i++) {
    snake.push({x: startX - i, y: startY});
}
```

### 碰撞检测算法
- 边界检测：检查蛇头坐标是否在 [0, tileCount) 范围内
- 自身检测：检查蛇头是否与任何蛇身部分重叠

### 食物生成算法
- 随机选择位置
- 检查是否与蛇身重叠
- 重复直到找到有效位置
